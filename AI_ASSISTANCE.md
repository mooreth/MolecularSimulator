# AI Assistance and Development Attribution

MolecularSimulator was built through an extended collaboration between project creator **Tom Moore** and **ChatGPT (OpenAI, GPT-6)**. The contribution was substantial and is acknowledged here intentionally rather than being hidden behind a generic statement that AI tools were used.

## Contributions

### Tom Moore — project creator and lead developer

- Established the scientific goals, use cases, and engineering requirements.
- Directed the overall architecture and the sequence of development milestones.
- Made design and implementation decisions in collaboration with the assistant.
- Supplied domain knowledge and feedback from practical work with molecular systems.
- Ran the software in the target SAMSON/LAMMPS environment and reported integration results.
- Retains responsibility for project direction, review, and release decisions.

### ChatGPT (OpenAI, GPT-6) — AI development assistant

- Assisted with software architecture and implementation planning.
- Generated and refined substantial portions of Python code and configuration.
- Assisted with debugging, refactoring, and technical analysis.
- Helped prepare documentation, examples, and release materials.

## Attribution convention

For future commits in which ChatGPT provides material assistance, the project may record that assistance in the commit message using this trailer:

```text
Assisted-by: ChatGPT (OpenAI, GPT-6)
```

This follows the spirit of the `Assisted-by:` convention used in projects such as the Linux kernel. It is a provenance acknowledgement, not a `Co-authored-by:` claim. The project does not identify ChatGPT as a human author or legal co-author.

## Copyright and licensing note

The MIT `LICENSE` file identifies Tom Moore as the project's copyright claimant for copyrightable project contributions. It does not claim that an AI system owns copyright. Under OpenAI's Terms of Use, output ownership is assigned to the user as between the user and OpenAI, to the extent permitted by law. Whether particular AI-generated material is itself copyrightable is a separate legal question; the U.S. Copyright Office's current guidance distinguishes human-authored expression and creative human selection, arrangement, or modification from purely AI-generated material.

The MIT license applies to the project to the extent the relevant material is protectable and licensable by the project rights holder. This note is a transparency statement, not legal advice or a legal determination about the copyright status of every line of code.
